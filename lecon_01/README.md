# Leçon 01 — Variables, types et premiers programmes

## Ce qu'on a appris

- Créer une **variable** et lui donner une valeur avec `=`
- Les 4 types de base : `int`, `float`, `str`, `bool`
- Afficher des valeurs avec `print()` et les **f-strings**
- Demander une saisie avec `input()` et convertir avec `int()`
- Les opérateurs arithmétiques : `+`, `-`, `*`, `/`, `//`, `%`, `**`

## Mots importants

| Mot | Signification |
|---|---|
| `variable` | Une boîte qui stocke une valeur |
| `int` | Nombre entier (42, -7, 0) |
| `float` | Nombre décimal (3.14, 1.5) |
| `str` | Texte entre guillemets ("Bonjour") |
| `bool` | Vrai (`True`) ou Faux (`False`) |
| `print()` | Affiche quelque chose dans la console |
| `input()` | Attend que l'utilisateur tape quelque chose |
| `int()` | Convertit du texte en nombre entier |
| `f"..."` | F-string — mélange texte et variables avec `{}` |
