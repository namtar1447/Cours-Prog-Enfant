Variables — Les boîtes de ton programme

🎮 Analogie

Imagine la fiche de personnage d'un RPG. Ton héros a des points de vie, un niveau, un nom…

Chaque information est dans une boîte avec une étiquette. En Python, on appelle ces boîtes des variables.

nom"Héros"
niveau1
vies3
score0
🐍 En Python
# Pour créer une variable : étiquette = valeur nom = "Héros" niveau = 1 vies = 3 score = 0
Le signe = en Python, c'est une flèche :
score = 100  signifie « mets la valeur 100 dans la boîte score ».

Changer la valeur d'une variable

Une variable peut changer — c'est pour ça qu'on l'appelle variable !

vies = 3 # vies vaut 3 vies = vies - 1 # on perd une vie → vies vaut 2 vies = vies + 5 # on gagne 5 vies → vies vaut 7

Clique sur les boutons pour simuler une partie :

Types de données — Différentes sortes de valeurs

🎮 Analogie

Dans un jeu, il y a différentes sortes d'objets : une épée (avec des dégâts entiers), une potion (avec un pourcentage décimal), le nom d'un héros (du texte), un interrupteur activé / désactivé.

Python fait pareil — chaque valeur a un type. Le type dit à Python comment utiliser la valeur.

Python a 4 types de base. Clique sur chacun pour voir des exemples :

int
🔢
Nombre entier
42, −7, 0, 1000
float
📊
Nombre décimal
3.14, 0.5, −2.7
str
💬
Texte (string)
"Bonjour", "Python"
bool
💡
Vrai ou Faux
True, False

Les 4 types dans le code

# int — nombre entier (pas de point) vies = 3 # float — nombre décimal (avec un point, pas une virgule !) vitesse = 1.5 # str — texte entre guillemets heros = "Gandalf" # bool — vrai ou faux (majuscule obligatoire !) en_vie = True game_over = False
⚠️ Attention : En Python, le séparateur décimal est le point — 1.5 est correct, mais 1,5 provoquerait une erreur !

Vérifier le type d'une valeur

type(42) # → <class 'int'> type(3.14) # → <class 'float'> type("Bonjour") # → <class 'str'> type(True) # → <class 'bool'>

🧠 Quiz — Section 2

🔢 int — c'est le nombre 100
💬 str — c'est du texte entre guillemets
📊 float — ça ressemble à un nombre
💡 bool — vrai ou faux

print() — Parler à l'écran

🎮 Analogie

Dans Scratch, tu avais le bloc « Dire … » pour qu'un personnage affiche un message.

En Python, print() fait la même chose — il affiche quelque chose dans la console.

🐍 Utilisation de base
print("Bonjour, monde !")
Bonjour, monde !
print(42)
42
print(3 + 4)
7

Afficher la valeur d'une variable

score = 250 print(score)
250

Combiner texte et variable — la f-string

nom = "Adam" score = 150 print(f"Joueur : {nom}, Score : {score}")
Joueur : Adam, Score : 150
La f-string : mets un f juste avant les guillemets, puis utilise {nom_de_variable} pour insérer des valeurs directement dans le texte. C'est comme remplir les blancs d'une phrase !

input() — Écouter l'utilisateur

🎮 Analogie

Quand un jeu démarre et affiche « Entrez votre nom : », il utilise quelque chose comme input().

input() met le programme en pause et attend que tu appuies sur Entrée.

prenom = input("Quel est ton prénom ? ") print(f"Bonjour, {prenom} !")
1
Affiche « Quel est ton prénom ? » et se met en pause.
2
L'utilisateur tape quelque chose et appuie sur ↵ Entrée.
3
Ce texte est stocké dans la variable prenom.
4
Le programme continue et affiche le message.

⚠️ input() retourne TOUJOURS du texte !

Même si l'utilisateur tape 42, Python reçoit le texte "42", pas le nombre 42.

Pour faire des calculs, il faut convertir avec int() ou float() :

# ❌ Sans conversion a = input("Nombre : ") # l'utilisateur tape 5 → a = "5" (texte) b = input("Nombre : ") # l'utilisateur tape 3 → b = "3" (texte) print(a + b) # affiche : 53 ← collage de texte, pas une addition ! # ✅ Avec conversion a = int(input("Nombre : ")) # a = 5 (entier) b = int(input("Nombre : ")) # b = 3 (entier) print(a + b) # affiche : 8 ✓
