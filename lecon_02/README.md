# Leçon 02 — Conditions (if / elif / else)

## Ce qu'on a appris
- Prendre des décisions dans un programme avec `if` et `else`
- Choisir parmi plusieurs cas avec `elif`
- Comparer des valeurs avec `==`, `!=`, `<`, `>`, `<=`, `>=`
- Combiner des conditions avec `and`, `or`, `not`
- Protéger un programme contre les erreurs prévisibles (ex. division par zéro)

## Mots importants
| Mot | Signification |
|---|---|
| `if` | « Si… » — vérifie une condition |
| `elif` | « Sinon si… » — teste une autre condition |
| `else` | « Sinon » — ce qui se passe quand rien d'autre ne correspond |
| `==` | « Est égal à » (deux signes égal pour comparer) |
| `!=` | « N'est pas égal à » |
| condition | Une question à laquelle Python répond `True` ou `False` |
