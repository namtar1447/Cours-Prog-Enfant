if / else — Choisir un chemin

🎮 Analogie

Dans un jeu RPG, quand tu arrives à un pont gardé : « Si tu as 10 pièces d'or, tu passes. Sinon, tu fais demi-tour. »

Le garde évalue une condition et prend un chemin ou l'autre. En Python, c'est exactement ce que fait if / else.

🐍 Syntaxe
if condition: # exécuté si la condition est VRAIE (True) else: # exécuté si la condition est FAUSSE (False)
Deux règles importantes :
  • La condition se termine toujours par :
  • Le code à l'intérieur est indenté (décalé avec la touche Tab)
🐍 Exemple concret
or = int(input("Combien de pièces d'or ? ")) if or >= 10: print("Le garde te laisse passer. Bonne route !") else: print("Pas assez d'or. Reviens quand tu seras riche !")

elif — Plusieurs chemins

🎮 Analogie

Dans un RPG, ton personnage peut avoir plusieurs états : plein de vie → attaque, blessé → défends-toi, presque mort → fuis !

Ce ne sont plus deux choix, mais plusieurs. C'est le rôle de elif (abréviation de else if).

🐍 Syntaxe
if condition_1: # si condition_1 est vraie elif condition_2: # si condition_1 est fausse ET condition_2 est vraie elif condition_3: # si les deux premières sont fausses ET condition_3 est vraie else: # si TOUTES les conditions sont fausses
Python teste les conditions dans l'ordre et s'arrête à la première qui est vraie. Le bloc else est optionnel.
🐍 Exemple — IA de combat RPG
pv = int(input("Combien de PV ? ")) if pv >= 50: print("⚔️ Attaque ! Tu es en pleine forme.") elif pv >= 20: print("🛡️ Défends-toi ! Tu es blessé.") elif pv >= 1: print("🏃 Fuis ! Tu es en danger de mort !") else: print("💀 Game over...")

and, or, not — Combiner les conditions

🎮 Analogie

Pour entrer dans un donjon : « Tu dois avoir une torche ET une épée. »

Pour déclencher une alarme : « Si la porte s'ouvre OU si la fenêtre se brise. »

Pour un passage secret : « Si tu n'es PAS un ennemi. »

🕹️ Démo interactive — Active les interrupteurs

and

Les DEUX doivent être True

A = True
B = True
A and B → True

or

Au moins UNE doit être True

A = True
B = False
A or B → True

not

Inverse la condition

A = True
not A → False
🐍 Dans le code
torche = True epee = False ennemi = False if torche and epee: print("Tu peux entrer dans le donjon !") if not ennemi: print("Tu peux passer le portail.")

Calculatrice intelligente

On reprend la calculatrice de la leçon 01 et on la rend plus résistante aux erreurs grâce aux conditions.

Problème 1 — Division par zéro

Que se passe-t-il si l'utilisateur tape 0 comme diviseur ?

a = int(input("Numérateur : ")) b = int(input("Dénominateur : ")) if b == 0: print("⚠️ Impossible de diviser par zéro !") else: print(f"{a} ÷ {b} = {a / b}")

Problème 2 — Nombre négatif dans une racine carrée

n = int(input("Racine carrée de : ")) if n < 0: print("⚠️ Pas de racine carrée d'un nombre négatif !") else: print(f"√{n} = {n ** 0.5}")
🕹️ Calculatrice intelligente — Essaie !
📌 À retenir : vérifier les conditions avant de faire le calcul évite les erreurs qui font planter le programme. C'est le principe de la validation.
