📦 Leçon 05 — Listes et dictionnaires

Objectifs
  • Stocker plusieurs valeurs dans une liste
  • Ajouter, lire et supprimer des éléments d'une liste
  • Associer des clés à des valeurs avec un dictionnaire
  • Combiner listes et fonctions pour garder un historique de calculs
Pourquoi listes et dictionnaires ?

Jusqu'ici, chaque variable ne stocke qu'une seule valeur à la fois. Si tu veux garder les 10 derniers calculs de ta calculatrice, il te faudrait 10 variables différentes !

Les listes et les dictionnaires te permettent de stocker autant de valeurs que tu veux dans une seule variable.

Les listes — Le sac à dos du héros

Analogie

Une liste, c'est comme un sac à dos numéroté : chaque compartiment a un numéro (0, 1, 2…) et contient un objet. Tu peux ajouter des objets, en retirer, et regarder ce qu'il y a dans chaque compartiment.

# Créer une liste inventaire = ["épée", "bouclier", "potion"] # Lire un élément par son index (commence à 0 !) print(inventaire[0]) # ▶ épée print(inventaire[2]) # ▶ potion # Connaître la taille print(len(inventaire)) # ▶ 3
⚠ Index commence à 0 !

Le premier élément est toujours à l'index 0, pas 1. Une liste de 3 éléments a les index 0, 1 et 2.

🎮 Démo — Clique sur un compartiment

inventaire = ["⚔️ épée", "🛡️ bouclier", "🧪 potion", "🗺️ carte"]

Modifier une liste — append, pop, for

inventaire = ["épée", "bouclier"] # Ajouter à la fin inventaire.append("potion") # → ["épée", "bouclier", "potion"] # Supprimer et récupérer le dernier élément dernier = inventaire.pop() # dernier = "potion" / inventaire = ["épée", "bouclier"] # Parcourir tous les éléments for objet in inventaire: print(objet)

Les dictionnaires — La fiche du héros

Analogie

Un dictionnaire, c'est comme la fiche de personnage d'un jeu de rôle : chaque information a un nom (la clé) et une valeur.

Au lieu de chercher par numéro (index 0, 1, 2…), tu cherches par nom : "pv", "force", "niveau".

# Créer un dictionnaire heros = { "nom" : "Arthur", "pv" : 100, "force" : 42, "niveau" : 5, } # Lire une valeur print(heros["nom"]) # ▶ Arthur print(heros["pv"]) # ▶ 100 # Modifier une valeur heros["pv"] = 85 # Ajouter une nouvelle clé heros["magie"] = 20
Liste

Accès par numéro : liste[0]

Pratique pour des séquences ordonnées

Dictionnaire

Accès par nom : dico["clé"]

Pratique pour décrire un objet avec des propriétés

🎮 Démo — La fiche de personnage

heros = { "nom": "Arthur", "pv": 100, "force": 42, "niveau": 5 }

🧠 Quiz — Comment lire la valeur associée à "force" ?

Combo — Historique de calculs

Objectif

On va combiner tout ce qu'on a appris : une liste pour garder l'historique, une fonction pour ajouter un calcul, et une boucle pour tout afficher.

C'est exactement comme ça que fonctionne l'historique d'une vraie calculatrice !

historique = [] # liste vide au départ def calculer(a, op, b): if op == "+": resultat = a + b elif op == "-": resultat = a - b elif op == "*": resultat = a * b else: resultat = a / b entree = f"{a} {op} {b} = {resultat}" historique.append(entree) # on sauvegarde return resultat # Quelques calculs… calculer(10, "+", 5) calculer(8, "*", 3) calculer(20, "-", 7) # Afficher l'historique for i, entree in enumerate(historique): print(f"[{i+1}] {entree}")
Nouveau : enumerate()

for i, elem in enumerate(liste): donne en même temps le numéro (i) et la valeur (elem) — pratique pour afficher un historique numéroté.

À retenir absolument
  • Les index des listes commencent à 0
  • append() ajoute à la fin, pop() retire le dernier
  • Un dictionnaire s'accède par clé : dico["clé"]
  • On peut stocker n'importe quoi dans une liste : des nombres, des mots, même d'autres listes !
