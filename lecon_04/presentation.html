Créer une fonction — def

Analogie — recette de cuisine
🍳 def nom():   →  écrire la recette (une seule fois) 🍽️ nom()         →  cuisiner (autant de fois qu'on veut)
# 1. On écrit la recette (la définition) def dire_bonjour(): print("Bonjour, aventurier !") # 2. On utilise la recette (l'appel) dire_bonjour() dire_bonjour() dire_bonjour()
Les deux étapes
  • Définir  def nom(): — Python mémorise, rien ne se passe
  • Appeler  nom() — Python exécute
  • Même fonction → autant d'appels qu'on veut

Les paramètres — Personnaliser la fonction

Analogie — ingrédients à choisir
🎂 « gâteau au chocolat »    →  sans paramètre (recette fixe) 🎂 « gâteau à la [saveur] »  →  avec paramètre (tu choisis à chaque appel)
def saluer_heros(nom): print(f"Bienvenue, {nom} ! Tu es prêt pour l'aventure.") saluer_heros("Arthur") saluer_heros("Zara") saluer_heros("Dragon-Maître")
Vocabulaire
  • Paramètre — dans la définition : def saluer_heros(nom):
  • Argument — à l'appel : saluer_heros("Arthur")

Plusieurs paramètres

Une fonction peut recevoir plusieurs informations à la fois — sépare-les par des virgules :

def attaquer(ennemi, degats): print(f"Tu attaques {ennemi} et lui infliges {degats} points de dégâts !") attaquer("Gobelin", 15) attaquer("Dragon", 42)

return — La fonction qui répond

Analogie
📢 print() dans la fonction  →  le vendeur crie le résultat 📦 return                  →  la machine envoie le résultat
Sans return
def double(n): print(n * 2) double(5) # affiche 10 # Mais on ne peut pas stocker ! x = double(5) # x vaut None (rien)
Avec return
def double(n): return n * 2 x = double(5) # x vaut 10 — on peut le réutiliser ! print(x) print(double(7) + 1) # 15

Combiner des fonctions — La vraie puissance

Analogie — pièces de LEGO
🧱 chaque fonction = une pièce  →  assembler = programme complet

Quand une fonction retourne une valeur, on peut l'utiliser comme ingrédient d'un calcul, ou la passer à une autre fonction :

def carre(n): return n * n def perimetre_carre(cote): return 4 * cote def describe_carre(cote): aire = carre(cote) perimetre = perimetre_carre(cote) print(f"Côté = {cote} → Aire = {aire} | Périmètre = {perimetre}") describe_carre(3) describe_carre(5) describe_carre(10)

🎮 Démo — Calculatrice de carré

Côté = 5
Pourquoi c'est puissant ?
  • Pas de répétition : tu écris le calcul une fois, tu l'utilises partout
  • Facile à corriger : si tu corriges une fonction, tout le programme en profite
  • Lisible : describe_carre(5) dit clairement ce que ça fait
5

À retenir absolument
  • def écrit la recette — l'appel l'exécute
  • Les paramètres permettent de personnaliser le comportement à chaque appel
  • return envoie un résultat qu'on peut stocker ou réutiliser
  • Sans return, la fonction retourne None
