Les tokens — comment lire 12+3×4

Analogie — lire une phrase
📖 "12+3×4"  →  pour l'ordinateur, six caractères (pas un calcul) ✂️ Découper       →  en mots : 12 + 3 × 4 🔢 Réduire        →  le plus prioritaire d'abord, jusqu'à un seul morceau
Un token
  • Token  = un morceau — un nombre, ou un symbole
  • Découper  "12+3" → [12, "+", 3]
  • Chiffres collés  1 puis 2 → 12, pas deux nombres

⚠ Toujours × et ÷ avant + et −

try / except — attraper les erreurs

Analogie — filet de sécurité
😰 Sans filet → une erreur → tout s'arrête en rouge 🎪 try / except → le filet attrape l'erreur sans tomber

Sans try/except vs. avec try/except

# L'utilisateur tape "abc" n = int(input("Nombre : ")) # ❌ ValueError — programme planté

❌ Traceback rouge dans Thonny

try: n = int(input("Nombre : ")) except ValueError: print("❌ Ce n'est pas un nombre !")

✅ Message clair — programme continue

Les deux erreurs à connaître

try: n = int(input("Entrez un nombre : ")) résultat = 10 / n print(f"10 ÷ {n} = {résultat}") except ValueError: print("❌ Ce n'est pas un nombre !") # ex: "abc", "salut" except ZeroDivisionError: print("❌ Impossible de diviser par zéro !") # ex: 0

🎮 Démo — Que se passe-t-il ?

L'utilisateur entre :

try :
    n = int(input("Nombre : "))
    résultat = 10 / n
    print(f"10 ÷ n = résultat")  ✅
except ValueError :
    print("❌ Ce n'est pas un nombre !")
except ZeroDivisionError :
    print("❌ Impossible de diviser par zéro !")

Résumé

SyntaxeCe que ça faitExemple
Token Un morceau de l'expression : un nombre ou un symbole "12+3" → [12, "+", 3]
Priorité × et ÷ se réduisent avant + et − 12+3×4 → 12+12 → 24
mpmath.sqrt / root / factorial Racine, racine n-ième, factorielle — à précision réglable mpmath.root(8, 3) → 2
liste.append(dictionnaire) Ajoute un calcul à l'historique {"expression": …, "resultat": …}
list(reversed(liste)) Une copie à l'envers — sans abîmer l'originale .reverse() modifie, reversed() copie
dictionnaire.get(clé, défaut) Cherche sans planter si la clé n'existe pas MESSAGES.get(nom, "❌ Erreur")
try / except ValueError Attrape un calcul impossible int("abc") → ValueError
except ZeroDivisionError Attrape une division par zéro 10 / 0 → ZeroDivisionError
À retenir
  • Un programme découpe le texte en tokens avant de calculer quoi que ce soit
  • Les priorités se font en plusieurs passes : × et ÷ d'abord, + et − ensuite
  • import permet de découper ton propre projet en modules
  • try/except + un dictionnaire = des messages d'erreur clairs
