customtkinter — fenêtres et boutons

Analogie — LEGO pour interfaces
🏠 CTk()            →  la plaque de base (la fenêtre) 🔤 CTkLabel()      →  une étiquette de texte 🔵 CTkButton()     →  un bouton cliquable 📝 CTkEntry()      →  une case de saisie
📦 Installation (une seule fois dans Thonny)

Outils → Gérer les paquets → chercher customtkinter → Installer

import customtkinter as ctk fenetre = ctk.CTk() # créer la fenêtre fenetre.title("Ma calculatrice") # titre fenetre.geometry("400x300") # largeur × hauteur px label = ctk.CTkLabel(fenetre, text="Résultat : 0") label.pack(pady=20) # placer dans la fenêtre btn = ctk.CTkButton(fenetre, text="=", command=calculer) btn.pack() fenetre.mainloop() # lancer — attend les clics
command=
  • command=calculer → appelle calculer() au clic
  • command=lambda: ... → action courte en une ligne
  • Pas de parenthèses après le nom de la fonction !

Tracer une courbe (version simple)

import matplotlib.pyplot as plt import numpy as np x = np.linspace(-5, 5, 200) # 200 points entre -5 et 5 y = x**2 # f(x) = x² plt.plot(x, y, color='#7c6af7') plt.title("y = x²") plt.show() # ouvre une fenêtre avec le graphique

Intégrer le graphique dans la fenêtre CTk

from matplotlib.figure import Figure from matplotlib.backends.backend_tkagg import FigureCanvasTkAgg fig = Figure(figsize=(5, 4), dpi=100) # la feuille de papier ax = fig.add_subplot(111) # la zone de dessin ax.plot(x, y, color='#7c6af7') canvas = FigureCanvasTkAgg(fig, master=fenetre) # coller dans CTk canvas.draw() canvas.get_tk_widget().pack()

try / except — attraper les erreurs

Analogie — filet de sécurité
😰 Sans filet → une erreur → tout s'arrête en rouge 🎪 try / except → le filet attrape l'erreur sans tomber

Sans try/except vs. avec try/except

# L'utilisateur tape "abc" n = int(input("Nombre : ")) # ❌ ValueError — programme planté

❌ Traceback rouge dans Thonny

try: n = int(input("Nombre : ")) except ValueError: print("❌ Ce n'est pas un nombre !")

✅ Message clair — programme continue

Les deux erreurs à connaître

try: n = int(input("Entrez un nombre : ")) résultat = 10 / n print(f"10 ÷ {n} = {résultat}") except ValueError: print("❌ Ce n'est pas un nombre !") # ex: "abc", "salut" except ZeroDivisionError: print("❌ Impossible de diviser par zéro !") # ex: 0

🎮 Démo — Que se passe-t-il ?

L'utilisateur entre :

try :
    n = int(input("Nombre : "))
    résultat = 10 / n
    print(f"10 ÷ n = résultat")  ✅
except ValueError :
    print("❌ Ce n'est pas un nombre !")
except ZeroDivisionError :
    print("❌ Impossible de diviser par zéro !")

Résumé

SyntaxeCe que ça faitExemple
import customtkinter as ctk Charge la bibliothèque de fenêtres ctk.CTk() → fenêtre
CTkButton(command=f) Bouton — appelle f() au clic CTkButton(text="=", command=calc)
fenetre.mainloop() Lance la boucle d'événements toujours à la fin
np.linspace(a, b, n) n points réguliers entre a et b linspace(-5, 5, 200)
ax.plot(x, y) Trace la courbe dans la figure ax.plot(x, x**2)
FigureCanvasTkAgg(fig, master=f) Intègre matplotlib dans CTk canvas.get_tk_widget().pack()
try / except ValueError Attrape une saisie invalide int("abc") → ValueError
except ZeroDivisionError Attrape une division par zéro 10 / 0 → ZeroDivisionError
À retenir
  • CTkButton(command=f) → pas de parenthèses après f
  • np.linspace génère les points x pour tracer une courbe
  • FigureCanvasTkAgg colle matplotlib dans la fenêtre CTk
  • try/except empêche le programme de planter sur une erreur de saisie
