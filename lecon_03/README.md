# Leçon 03 — Boucles (for / while)

## Ce qu'on a appris
- Répéter des instructions avec `for i in range()`
- Contrôler le nombre de répétitions et le point de départ avec `range(début, fin, pas)`
- Parcourir tous les éléments d'une liste avec `for elem in liste`
- Répéter tant qu'une condition est vraie avec `while`
- Toujours modifier la variable dans un `while` pour éviter la boucle infinie

## Mots importants
| Mot | Signification |
|---|---|
| `for` | Répète exactement N fois |
| `while` | Répète tant qu'une condition est vraie |
| `range(n)` | Génère les nombres 0, 1, 2, …, n−1 |
| `range(a, b)` | Génère les nombres a, a+1, …, b−1 |
| `range(a, b, pas)` | Génère les nombres en sautant de `pas` en `pas` |
| boucle infinie | Boucle qui ne s'arrête jamais — toujours modifier la variable ! |
